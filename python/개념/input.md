# input

## 한 줄 정의
키보드로 값을 **입력받는** 함수. 입력한 값은 **항상 문자열(`str`)**이다.

## 비유
웹사이트 회원가입 폼과 같다. 나이 칸에 `25`를 입력해도 서버에는 글자 `"25"`로 전달되고, 계산하려면 숫자로 바꿔야 한다.

## 기본 모양
```python
name = input("이름: ")          # "이름: "을 보여주고 입력을 기다림
print(name + "님 안녕하세요")

price = input("가격: ")         # 120 입력
print(type(price))              # <class 'str'>  ← 숫자를 쳐도 문자열!
print(price * 2)                # 120120

price = int(input("가격: "))    # 받자마자 int로 변환 (괄호 두 겹)
print(price * 2)                # 240
```

## 변환 시점
| 방법 | 코드 | 언제 좋은가 |
|---|---|---|
| 쓸 때 변환 | `price = input(...)` → `int(price)*2` | 한 번만 쓸 때 |
| 받자마자 변환 | `price = int(input(...))` | 여러 번 계산할 때 |

## 자주 하는 실수
- 입력값을 그대로 계산: `input(...) + 10` → `TypeError`
- 숫자가 아닌 값을 입력한 채 `int()`: `int("N/A")` → `ValueError`
- 코랩에서 입력 칸에 Enter를 안 누르고 다른 셀 실행 → 멈춘 것처럼 보임
