# input

## 한 줄 정의
키보드로 값을 **입력받는** 함수. 입력한 값은 **항상 문자열(`str`)**이다.

## 비유
지금까지는 악보(코드)에 음을 미리 다 적어 뒀다. `input`은 연주 중에 관객에게 "신청곡 받아요!" 하고 묻는 것. 무슨 곡이 올지는 실행해 봐야 안다.

## 기본 모양
```python
name = input("이름: ")        # "이름: "을 보여주고 입력을 기다림
print(name + "님 안녕하세요")

bpm = input("BPM: ")          # 120 입력
print(type(bpm))              # <class 'str'>  ← 숫자를 쳐도 문자열!
print(bpm * 2)                # 120120

bpm = int(input("BPM: "))     # 받자마자 int로 변환 (괄호 두 겹)
print(bpm * 2)                # 240
```

## 변환 시점
| 방법 | 코드 | 언제 좋은가 |
|---|---|---|
| 쓸 때 변환 | `bpm = input(...)` → `int(bpm)*2` | 한 번만 쓸 때 |
| 받자마자 변환 | `bpm = int(input(...))` | 여러 번 계산할 때 |

## 자주 하는 실수
- 입력값을 그대로 계산: `input(...) + 10` → `TypeError`
- 숫자가 아닌 값을 입력한 채 `int()`: `int("Am")` → `ValueError`
- 코랩에서 입력 칸에 Enter를 안 누르고 다른 셀 실행 → 멈춘 것처럼 보임
