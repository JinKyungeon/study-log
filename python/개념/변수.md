# 변수

## 한 줄 정의
값에 **이름표를 붙여 저장**해 두고, 나중에 그 이름으로 꺼내 쓰는 것.

## 비유
엑셀에서 `B2` 셀에 "재고"라는 이름을 붙여 두면, 위치를 기억하지 않아도 이름으로 값을 찾을 수 있다. 셀 값을 고쳐 쓰듯 변수 값도 나중에 바꿀 수 있다.

## 기본 모양
```python
product = "notebook"   # = 는 "같다"가 아니라 "오른쪽 값을 왼쪽 이름에 넣어라"
stock = 120
print(product)         # notebook
print(stock)           # 120

stock = 90             # 다시 넣으면 새 값으로 바뀐다
print(stock)           # 90
```

## 이름 규칙
- 영문자, 숫자, `_` 사용 가능 (한글도 되지만 영어 권장)
- 숫자로 시작하면 안 됨: `1st_sales` ❌ → `sales_1` ✅
- 띄어쓰기 불가: `total sales` ❌ → `total_sales` ✅
- `print` 같은 파이썬 예약어·함수 이름은 피하기

## 자주 하는 실수
- 대소문자를 다르게 씀: `product = "notebook"` 후 `print(Product)` → `NameError` (다른 변수로 본다)
- 변수 이름에 따옴표를 씀: `print("product")` → 값이 아니라 글자 `product`가 출력됨
- 글자와 변수 사이 쉼표 누락: `print("총 초=" minutes*60+seconds)` → `SyntaxError` (2026-10-07 실수)
- 계산해서 보여주기만 하고 값은 안 바꿈: `print(stock+20)` → 화면엔 `140`, `stock`은 그대로 `120` (2026-10-07 실수)

## 값을 갱신하기
```python
stock = 100
stock = stock + 20   # 오른쪽 먼저: 100 + 20 = 120 → stock에 다시 넣음
print(stock)         # 120
```
