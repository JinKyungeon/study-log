# 변수

## 한 줄 정의
값에 **이름표를 붙여 저장**해 두고, 나중에 그 이름으로 꺼내 쓰는 것.

## 비유
DAW(작곡 프로그램)의 트랙 이름과 같다. 트랙에 "Bass"라고 이름을 붙여 두면, 안에 뭐가 들었는지 매번 열어보지 않아도 이름으로 찾을 수 있다. 내용(값)은 나중에 바꿔 끼울 수도 있다.

## 기본 모양
```python
key = "C major"     # = 는 "같다"가 아니라 "오른쪽 값을 왼쪽 이름에 넣어라"
bpm = 120
print(key)          # C major
print(bpm)          # 120

bpm = 90            # 다시 넣으면 새 값으로 바뀐다
print(bpm)          # 90
```

## 이름 규칙
- 영문자, 숫자, `_` 사용 가능 (한글도 되지만 영어 권장)
- 숫자로 시작하면 안 됨: `1st_chord` ❌ → `chord_1` ✅
- 띄어쓰기 불가: `my key` ❌ → `my_key` ✅
- `print` 같은 파이썬 예약어·함수 이름은 피하기
