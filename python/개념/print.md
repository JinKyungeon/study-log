# print

## 한 줄 정의
괄호 안의 내용을 **화면에 출력**하는 파이썬의 기본 함수.

## 비유
악보를 연주자에게 "소리 내서 들려줘"라고 하는 것. 컴퓨터 속 값은 원래 보이지 않고, `print`를 해야 우리 눈에 보인다.

## 기본 모양
```python
print("안녕하세요")        # 글자(문자열)는 따옴표로 감싼다
print(3 + 4)              # 숫자 계산 결과: 7
print("C", "E", "G")      # 쉼표로 여러 개 → 사이에 공백: C E G
```

## 자주 하는 실수
- 따옴표를 한쪽만 닫음 → `SyntaxError`
- `Print`처럼 대문자로 씀 → `NameError` (파이썬은 대소문자를 구분)
- 글자와 값 사이 쉼표를 빠뜨림 → `SyntaxError: ... Perhaps you forgot a comma?`
- 출력 예측할 때 따옴표 **밖** 쉼표도 찍힌다고 착각 → 실제로는 공백 한 칸 (`print("2+3", 2+3)` → `2+3 5`)
