# 자료형

## 한 줄 정의
값의 **종류**. 종류에 따라 같은 `+`도 다르게 동작한다.

## 비유
엑셀에서 숫자 `3`과 텍스트 `'3`은 똑같이 보이지만, 텍스트로 저장된 `'3`은 SUM에 더해지지 않는다. 파이썬도 `3`(숫자)과 `"3"`(문자열)을 완전히 다른 것으로 본다.

## 종류
| 자료형 | 이름 | 예시 |
|---|---|---|
| 정수 | `int` | `120`, `-3` |
| 실수 | `float` | `3.5`, `0.25` |
| 문자열 | `str` | `"서울"`, `"120"` |
| 불 | `bool` | `True`, `False` (다음 시간) |

## 기본 모양
```python
print(type(120))     # <class 'int'>
print(type("120"))   # <class 'str'>  ← 따옴표가 있으면 숫자처럼 보여도 문자열

print(3 + 4)         # 7         ← 숫자 + 숫자 = 더하기
print("3" + "4")     # 34        ← 문자열 + 문자열 = 이어 붙이기
print("NA " * 3)     # NA NA NA  ← 문자열 * 숫자 = 반복
```

## 형 변환
값의 종류를 바꾸는 함수. 엑셀의 "텍스트를 숫자로 변환"과 같다. CSV 파일이나 입력값에서 숫자가 문자열로 들어오는 일이 많아서 실무에서 자주 쓴다.
```python
sales = 120
print("매출 " + str(sales))   # 매출 120  ← 숫자 → 문자열로 바꿔서 붙이기
print(int("7") + int("3"))   # 10        ← 문자열 → 숫자로 바꿔서 더하기
print(float("3.5"))          # 3.5
```

## 자주 하는 실수
- 문자열 + 숫자: `"매출 " + 120` → `TypeError` (종류가 달라서 못 붙임)
- 숫자 모양이 아닌 문자열을 `int()`: `int("N/A")`, `int("1,000")` → `ValueError` (종류는 OK, **값**이 문제)
- 따옴표 안 숫자를 숫자로 착각: `type("3.5")` → `str` (2026-10-07 실수)
- `type(3.5)`만 쓰고 `print` 안 함 → 화면에 안 나옴. 보려면 `print(type(3.5))` (2026-10-07 실수)

## 쉼표 vs `+`
| | 쉼표 `,` | `+` |
|---|---|---|
| 종류가 달라도? | ✅ `print("매출", 120)` | ❌ `TypeError` |
| 공백 | 한 칸 **자동** | 없음 → 직접 `"매출 "` |
| 결과 | `매출 120` | `print("매출 " + "120")` → `매출 120` |

## 관련 개념
- [[print]] — 쉼표로 섞으면 종류가 달라도 출력 가능: `print("매출", 120)`
- [[변수]] — 변수에 담긴 값에도 자료형이 있다
- [[input]] — 입력은 항상 문자열 → 계산하려면 `int()`
