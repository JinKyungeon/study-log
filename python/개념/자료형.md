# 자료형

## 한 줄 정의
값의 **종류**. 종류에 따라 같은 `+`도 다르게 동작한다.

## 비유
같은 "C"라도 악보의 음표(소리)인지, 가사 속 글자 "C"인지에 따라 쓰임이 다르다. 파이썬도 `3`(숫자)과 `"3"`(글자)을 완전히 다른 것으로 본다.

## 종류
| 자료형 | 이름 | 예시 |
|---|---|---|
| 정수 | `int` | `120`, `-3` |
| 실수 | `float` | `3.5`, `0.25` |
| 문자열 | `str` | `"Am"`, `"120"` |
| 불 | `bool` | `True`, `False` (다음 시간) |

## 기본 모양
```python
print(type(120))     # <class 'int'>
print(type("120"))   # <class 'str'>  ← 따옴표가 있으면 숫자처럼 보여도 문자열

print(3 + 4)         # 7     ← 숫자 + 숫자 = 더하기
print("3" + "4")     # 34    ← 문자열 + 문자열 = 이어 붙이기
print("Am" * 3)      # AmAmAm ← 문자열 * 숫자 = 반복
```

## 형 변환
값의 종류를 바꾸는 함수. 같은 곡을 악보 ↔ 음원으로 바꾸는 것.
```python
bpm = 120
print("BPM " + str(bpm))     # BPM 120  ← 숫자 → 문자열로 바꿔서 붙이기
print(int("7") + int("3"))   # 10       ← 문자열 → 숫자로 바꿔서 더하기
print(float("3.5"))          # 3.5
```

## 자주 하는 실수
- 문자열 + 숫자: `"BPM " + 120` → `TypeError` (종류가 달라서 못 붙임)
- 숫자 모양이 아닌 문자열을 `int()`: `int("Am")` → `ValueError` (종류는 OK, **값**이 문제)
- 따옴표 안 숫자를 숫자로 착각: `type("3.5")` → `str` (2026-10-07 실수)

## 쉼표 vs `+`
| | 쉼표 `,` | `+` |
|---|---|---|
| 종류가 달라도? | ✅ `print("BPM", 120)` | ❌ `TypeError` |
| 공백 | 한 칸 **자동** | 없음 → 직접 `"BPM "` |
| 결과 | `BPM 120` | `print("BPM " + "120")` → `BPM 120` |

## 관련 개념
- [[print]] — 쉼표로 섞으면 종류가 달라도 출력 가능: `print("BPM", 120)`
- [[변수]] — 변수에 담긴 값에도 자료형이 있다
