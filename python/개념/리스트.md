# 리스트 `[ ]`

## 한 줄 정의
값 여러 개를 **순서대로** 담는 그릇. 변수 하나에 여러 값을 넣는다.

## 왜 필요한가
3일 매출을 `sales_mon`, `sales_tue`, `sales_wed`로 따로 만들면 30일치는 변수 30개.
리스트면 `daily_sales = [12000, 8500, 15000]` 하나로 끝.
- 날마다의 매출·기온·미세먼지 측정값
- 학생 점수 목록
- 12월 CSV 분석: 파일의 한 열을 리스트에 담아 `for`로 계산

## 기본 모양
```python
daily_sales = [12000, 8500, 15000]   # 대괄호 + 쉼표
names = ["민수", "지영", "하준"]       # 글자도 가능
```
- 자료형 규칙은 그대로: 따옴표 없으면 `int`, 있으면 `str` (`["10"]`은 글자)

## 꺼내기 — 번호(인덱스)는 0부터
```
daily_sales = [12000, 8500, 15000]
번호:            0      1      2
```
```python
daily_sales[0]     # 12000 (첫 번째)
daily_sales[2]     # 15000 (세 번째)
len(daily_sales)   # 3 (개수)
```
- `range(3)`이 `0, 1, 2`인 것과 같은 규칙
- **마지막 번호 = `len(리스트) - 1`**
- 없는 번호를 쓰면 `IndexError: list index out of range` (= 리스트 번호가 범위 밖)

## for로 돌기
```python
for sales in daily_sales:     # 바퀴마다 값이 하나씩 sales에
    print(sales)
```
- `range` 대신 리스트를 바로 넣는다
- 이름 관례: 리스트는 복수(`scores`, `_values`), 꺼낸 하나는 단수(`score`)

## 자주 쓰는 패턴
| 패턴 | 시작값 (반복 밖 위) | 반복 안 | 반복 뒤 |
|---|---|---|---|
| 합계 | `total = 0` | `total = total + x` | |
| 조건 개수 | `count = 0` | `if 조건:` 안에서 `count = count + 1` | |
| 평균 | | | `total / len(리스트)` |
| 최댓값 | `max_x = 리스트[0]` | `if x > max_x:` → `max_x = x` | |

- 개수는 반복으로 세지 말고 `len()` (조건 개수만 반복으로)
- 같은 반복 안에서 `if` **안**(조건 맞는 것만) / **밖**(모두)을 들여쓰기로 구분

## 자주 하는 실수
- 최댓값 시작을 `0`으로 → 값이 모두 음수(`[-5, -3, -9]`)면 리스트에 없는 `0`이 답. 에러 없이 틀림 → **리스트 안의 값 `[0]`으로 시작** (2026-11-09)
- 합계를 담는 변수에 `average_` 이름 → 역할에 맞는 이름 (`total_` 합계, `average_` 평균) (2026-11-09)
- `len()`으로 알 수 있는 개수를 반복에서 또 셈 (2026-11-09)
