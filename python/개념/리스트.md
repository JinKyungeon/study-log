# 리스트 `[ ]`

## 한 줄 정의
값 여러 개를 **순서대로** 담는 그릇. 변수 하나에 여러 값을 넣는다.

## 왜 필요한가
3일 매출을 `sales_mon`, `sales_tue`, `sales_wed`로 따로 만들면 30일치는 변수 30개.
리스트면 `daily_sales = [12000, 8500, 15000]` 하나로 끝.
- 날마다의 매출·기온·미세먼지 측정값
- 학생 점수 목록
- 12월 CSV 분석: 파일의 한 열을 리스트에 담아 `for`로 계산

## 기본 모양
```python
daily_sales = [12000, 8500, 15000]   # 대괄호 + 쉼표
names = ["민수", "지영", "하준"]       # 글자도 가능
```
- 자료형 규칙은 그대로: 따옴표 없으면 `int`, 있으면 `str` (`["10"]`은 글자)

## 꺼내기 — 번호(인덱스)는 0부터
```
daily_sales = [12000, 8500, 15000]
번호:            0      1      2
```
```python
daily_sales[0]     # 12000 (첫 번째)
daily_sales[2]     # 15000 (세 번째)
len(daily_sales)   # 3 (개수)
```
- `range(3)`이 `0, 1, 2`인 것과 같은 규칙
- **마지막 번호 = `len(리스트) - 1`**
- 없는 번호를 쓰면 `IndexError: list index out of range` (= 리스트 번호가 범위 밖)
- **마지막 값** = `리스트[len(리스트) - 1]` — 길이가 바뀌어도 항상 마지막 (최근 데이터 볼 때)

## for로 돌기
```python
for sales in daily_sales:     # 바퀴마다 값이 하나씩 sales에
    print(sales)
```
- `range` 대신 리스트를 바로 넣는다
- 이름 관례: 리스트는 복수(`scores`, `_values`), 꺼낸 하나는 단수(`score`)

## 추가하기 — append
```python
daily_sales = []                       # 빈 리스트
daily_sales.append(12000)              # 맨 뒤에 하나 추가 → [12000]
```
- `리스트.append(값)` — 점(`.`) = "이 리스트**의** 기능"
- `for` + `input` + `append`로 입력값을 **모두** 남긴다 (누적은 합계 숫자 하나만 남음)

| | 누적 `total = total + x` | `append` |
|---|---|---|
| 남는 것 | 숫자 하나 | 값 전부 |
| 시작값 | `0` | `[]` |

**모으기 → 분석** 순서: 반복 ①에서 `append`만, 반복 ②에서 리스트를 돌며 계산. 다 모은 뒤라야 `리스트[0]`으로 시작할 수 있다.

## 자주 쓰는 패턴
| 패턴 | 시작값 (반복 밖 위) | 반복 안 | 반복 뒤 |
|---|---|---|---|
| 합계 | `total = 0` | `total = total + x` | |
| 조건 개수 | `count = 0` | `if 조건:` 안에서 `count = count + 1` | |
| 평균 | | | `total / len(리스트)` |
| 최댓값 | `max_x = 리스트[0]` | `if x > max_x:` → `max_x = x` | |
| 최솟값 | `min_x = 리스트[0]` | `if x < min_x:` → `min_x = x` | |
| 필터링 (골라 담기) | `picked = []` | `if 조건:` 안에서 `picked.append(x)` | `len(picked)` |
| 나눠 담기 | `a = []`, `b = []` | `if 조건:` → `a.append(x)` / `else:` → `b.append(x)` | |

- 개수는 반복으로 세지 말고 `len()` (조건 개수만 반복으로)
- 같은 반복 안에서 `if` **안**(조건 맞는 것만) / **밖**(모두)을 들여쓰기로 구분
- 한 값이 둘 중 하나에만 → `if`/`else`, 여러 곳에 동시에 → `if` 여러 개
- 반복을 나눌 때: 시작값이 리스트 안의 값(`[0]`)이면 **다 모은 뒤**. 합계·개수처럼 `0`/`[]`에서 시작하면 담으면서 같이 해도 됨

## 자주 하는 실수
- 최댓값 시작을 `0`으로 → 값이 모두 음수(`[-5, -3, -9]`)면 리스트에 없는 `0`이 답. 에러 없이 틀림 → **리스트 안의 값 `[0]`으로 시작** (2026-11-09)
- 합계를 담는 변수에 `average_` 이름 → 역할에 맞는 이름 (`total_` 합계, `average_` 평균) (2026-11-09)
- `len()`으로 알 수 있는 개수를 반복에서 또 셈 (2026-11-09)

- 최솟값인데 `if min_x < x:` (최댓값 방향) (2026-11-25)
- `min_temperature = temperatures` — s 하나로 리스트 전체를 담음 → 다음 비교에서 `TypeError: '<' not supported between instances of 'list' and 'int'` (2026-11-25)
- 평균을 반복 **안**에서 계산 → 마지막 바퀴가 덮어써서 우연히 맞음. 다 모은 뒤 계산은 반복 뒤 (2026-11-25)
- `append` 빠뜨려서 `[]` 출력, 입력받으며 바로 분석 → 모으기·분석 나누기 (2026-11-25) → 2026-11-27 접속자 분석 **한 번에** ✅
- `stock_list[len(stock_list) - 1]`을 다른 리스트·`[0]`으로 계산 → 괄호 안 리스트 이름부터 (2026-11-28)
