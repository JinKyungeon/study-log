# 반복문 (for)

## 한 줄 정의
들여 쓴 코드를 `range`가 꺼내는 숫자 **개수만큼** 반복한다.

## 왜 필요한가
`print("안녕")`을 5번, 100번 쓰는 대신 **같은 일을 여러 번** 시킨다.
- 구구단 1~9 출력
- 학생 3명 점수를 차례로 입력받기
- 여러 값을 하나씩 더해 합계 구하기

## 기본 모양
```python
for i in range(1, 4):         # ← 끝에 콜론 :
    print(i, "번째 반복")      # ← 들여쓰기(4칸): 3번 반복
print("반복 끝")               # ← 들여쓰기 없음: 반복이 끝난 뒤 1번
```
- `i` = 지금 꺼낸 숫자를 담는 [[변수]]. 반복할 때마다 값이 바뀐다 (이름은 자유, 관례로 `i`)
- 블록 안 vs 밖 규칙은 [[조건문]]과 같다
  - `if` 블록: 0번 또는 1번 / `for` 블록: `range` 개수만큼

## range
| 코드 | 꺼내는 숫자 | 개수 |
|---|---|---|
| `range(5)` | 0, 1, 2, 3, 4 | 5개 |
| `range(1, 6)` | 1, 2, 3, 4, 5 | 5개 |
| `range(2, 5)` | 2, 3, 4 | 3개 |

- **0부터** 시작 (시작을 안 쓰면)
- **끝은 "멈춤 표시"라 미포함** → 개수 = 끝 − 시작, `range(5)` = "5번 반복"
- 비유: 자에서 2cm~5cm 눈금 사이 칸은 3칸, 칸마다 시작 눈금 번호를 붙이면 2, 3, 4
- 이어 붙여도 안 겹침: `range(0, 5)` + `range(5, 10)` = 0 ~ 9

## 누적 패턴 — 합계 구하기
```python
total_score = 0                      # ← 반복 전: 아직 아무것도 안 더함

for i in range(1, 4):
    score = int(input(str(i)+"번 학생 점수: "))
    total_score = total_score + score   # ← 반복 안: 자기 자신에 더해 쌓기
print("총점", total_score)            # ← 반복 후: 한 번만 출력
```
- `score`는 매번 **덮어써짐**, `total_score`는 **쌓임**
- `total_score = 0`을 반복 안에 두면 매번 리셋 / `print`를 안에 두면 3번 출력

## 자주 하는 실수
- `range(1, 9)`로 1~9를 기대 → 9는 안 나옴. 9까지면 `range(1, 10)`
- 예측할 때 `print("줄", i)`의 순서를 바꿔 `0줄`로 적음 → 괄호 안 순서 그대로 (2026-10-20)
- `input`에 쉼표로 조각 넣기 → `input`은 하나의 글자만. `str(i)+"번 학생 점수: "`로 붙이기 (2026-10-20 스스로 해결)
- 지난 값을 `score(i)`로 꺼내려 함 → `TypeError: 'int' object is not callable`. 변수는 마지막 값만 남음 → 누적 변수로 따로 쌓기 (2026-10-20)

## 관련 개념
- [[조건문]] — `for` 안에 `if`를 넣으면 들여쓰기 두 겹 (4칸 + 4칸)
- [[변수]] — 누적은 `stock = stock + 20` 갱신 모양 그대로
- [[print]] — 쉼표로 이으면 숫자·글자가 섞여도 `str()` 불필요
- [[input]] — 안내문은 `+`로 하나의 글자를 만들어 넣기
- 다음: `while`
