# 불 (bool)

## 한 줄 정의
**참/거짓**을 나타내는 자료형. 값은 `True`, `False` 두 개뿐이다.

## 비유
엑셀에서 `=A1>100`을 쓰면 `TRUE`/`FALSE`가 나오는 것과 같다.

## 비교 연산자 → 결과는 항상 bool
| 연산자 | 뜻 | 예시 | 결과 |
|---|---|---|---|
| `>` | 크다 | `120 > 100` | `True` |
| `<` | 작다 | `120 < 100` | `False` |
| `>=` | 크거나 같다 | `100 >= 100` | `True` |
| `<=` | 작거나 같다 | `90 <= 100` | `True` |
| `==` | 같다 | `100 == 100` | `True` |
| `!=` | 다르다 | `100 != 100` | `False` |

## 기본 모양
```python
score = 85
print(score >= 60)          # True   ← 합격 기준 60점 이상?
print(type(score >= 60))    # <class 'bool'>  ← 따옴표 없음 → str 아님

stock = 0
print(stock == 0)           # True   ← 재고 소진?
```

## 비교 결과를 변수에 담기
비교 결과도 **값**이라서 상자(변수)에 담을 수 있다. 불 변수 이름에는 `is_`("~인가?")를 붙이는 습관이 있다.
```python
age = 15
is_allowed = age >= 13      # 오른쪽 계산 → True → is_allowed에 저장
if is_allowed:              # "입장이 허용되면" — 문장처럼 읽힘
    print("입장 가능")
```
- `if age >= 13:`도 사실은 계산된 `True`/`False` 하나를 보는 것 (2026-10-29 입장 확인 문제)

## `=` vs `==`
- `=` → **저장**: `score = 85`
- `==` → **같은지 비교**: `score == 85` → `True`
- `print(stock = 0)` → `TypeError: print() got an unexpected keyword argument 'stock'` (2026-10-11 문제)

## 자주 하는 실수
- `type(sales > target)`을 `str`로 예측 → `True`엔 따옴표가 없으니 `bool` (2026-10-11 실수)
- `"10" == 10`을 에러로 예측 → **`False`**. `+`는 종류가 다르면 에러지만 `==`는 묻기만 하므로 "달라"라고 대답 (2026-10-11 실수)
  - 실무 함정: 입력·CSV의 `"10"`과 숫자 `10`을 비교하면 에러 없이 조용히 `False` → 비교 전에 `int()`
- 예시 입력값(75)을 기준값(60) 자리에 씀 → 조건은 **문제 본문**에서 읽기 (2026-10-11)

| | `"10" + 10` | `"10" == 10` |
|---|---|---|
| 하는 일 | 붙이기/더하기 | 같은지 질문 |
| 종류가 다르면 | `TypeError` | `False` |
