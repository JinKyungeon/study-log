## 오늘 배운 것 / 헷갈린 것
### 1일차 (2026-10-07) — [[자료형]]: 숫자 vs 문자열
- `type(값)` = 값의 종류를 **알아내기만** 함 → 보려면 `print(type(3.5))` (괄호 두 겹 `))`)
  - **헷갈렸다가 이해함:** `type(3.5)`만 쓰면 아무것도 안 나옴
  - 계산하기 / 저장하기(`=`) / 보여주기(`print`)는 각각 따로 시켜야 하는 일
    - `print(stock+20)` = 보여주기만, 저장 X (1주차 3일차)
    - `type(3.5)` = 알아내기만, 보여주기 X
  - 코랩은 셀 **마지막 줄**의 값을 자동으로 보여주지만 원래 파이썬에선 안 됨 → 항상 `print`
- 문자열 `+` = 이어 붙이기: `"Data" + "Science"` → `DataScience`, `"10" + "20"` → `1020`
- 문자열 `*` = 반복: `"NA " * 4` → `NA NA NA NA ` (따옴표 안 공백도 반복됨)
- `*`가 `+`보다 먼저: `"A" * 2 + "B"` → `AA` + `B` → `AAB`
- 문자열 + 숫자 → `TypeError: can only concatenate str (not "int") to str`
  - 에러 메시지를 읽고 원인을 **스스로 추측해서 맞힘** ("타입이 매칭이 안 돼서")

| 문제 | 내 답 | 결과 | 확인하려는 개념 |
|---|---|---|---|
| 1-1 `type(3.5)` | `print` 없이 실행 → 아무것도 안 나옴 → `print(type(3.5))` | ⚠️→✅ | `type()` 사용법, 보여주기는 `print` |
| 1-2 `"Data" + "Science"` | `print("Data" + "Science")` | ✅ | 문자열 `+` |
| 1-3 `"NA " * 4` | `print("NA " *4)` | ✅ | 문자열 `*` |
| 2-1 `10 + 20` / `"10" + "20"` 예측 | `30` / `1020` | ✅ | 숫자 `+` vs 문자열 `+` |
| 2-2 `type("3.5")` 예측 | `float` | ❌ 정답 `<class 'str'>` | **따옴표가 있으면 숫자처럼 보여도 문자열** |
| 2-3 `"A" * 2 + "B"` 예측 | `AAB` | ✅ | 문자열 연산 + 계산 순서 |
| 4 `"매출 " + 120` 에러 추측 | "타입이 매칭이 안 돼서" | ✅ | `TypeError` 읽기 |

- **틀린 점:** `"3.5"`를 겉모양만 보고 실수라고 판단 → 종류는 **따옴표**가 결정한다
  - 2-1에서 `"10" + "20"` → `1020`은 맞혔으니 원리는 앎. 하지만 `type()` 문제에선 놓침 → 다음 세션 재확인

#### 보너스: `"매출 " + 120` 에러 고치기 → `매출 120`
| 방법 | 내 답 | 결과 |
|---|---|---|
| 1. 쉼표 | `print("매출", "120")` | ✅ (`120` 그대로 둬도 됨: 쉼표는 종류가 달라도 OK) |
| 2. `+` | `print("매출 " +"120")` | ✅ |

- **스스로 정리한 규칙:** 쉼표는 공백 한 칸을 **자동으로** 넣고, `+`는 넣지 않는다 → `+`를 쓸 땐 문자열 안에 공백을 직접 넣어야 한다
- 쉼표 = 종류가 달라도 나란히 출력 / `+` = 종류가 같아야 하고 빈틈없이 이어 붙임

### 2일차 (2026-10-07) — 형 변환 `str()`, `int()`
#### 복습 (안 보고 예측) — 5개 모두 정답
- `print(visitors + 10)` → `60`, 그다음 `print(visitors)` → `50` (보여주기 ≠ 저장) ✅
- `type("7")` → `<class 'str'>` (따옴표가 종류를 결정) ✅
- → 1일차 약한 개념 두 개 모두 회복

#### 개념
- 형 변환 = 값의 **종류를 바꾸는** 함수. 비유: 엑셀의 "텍스트를 숫자로 변환"
  - `str(120)` → `"120"` / `int("120")` → `120` / `float("3.5")` → `3.5`
- `"매출 " + 120`은 에러 → `"매출 " + str(sales)`로 해결 (변수 안 숫자도 OK)
- `input`은 항상 문자열로 받으므로 계산하려면 `int()`가 필요 (다음 시간)
- `int("N/A")` → `ValueError: invalid literal for int() with base 10: 'N/A'`
  - **TypeError vs ValueError:** `"매출 " + 120`은 종류 조합 자체가 안 됨(Type), `int("N/A")`는 문자열을 넣는 건 되지만 그 **값**이 정수 모양이 아님(Value)

| 문제 | 내 답 | 결과 | 확인하려는 개념 |
|---|---|---|---|
| 타이핑 1 | `print("매출 " + str(sales))` | ✅ | `str()` + 공백 위치 |
| 타이핑 2 | `print(int("7")+int("3"))` | ✅ | `int()` → `10` (안 바꾸면 `73`) |
| 1. `x * 3`, `int(x) * 3` 예측 | `555` / `15` | ✅ | 같은 `*`도 종류에 따라 반복 vs 곱셈 |
| 2. `type(str(100))`, `type(int("100"))` 예측 | `<class 'str'>` / `<class 'int'>` | ✅ | 형 변환 결과의 종류 |
| 3. `+`만으로 `총 210초` | `print("총 "+str(minutes*60+seconds)+"초")` | ✅ | 계산 → `str()` → 공백 위치 (종합) |
| 4. `int("N/A")` 에러 추측 | "타당한 정수가 아니라서" | ✅ | `ValueError` 읽기 |

- 오늘 문제 전부 정답, 에러 원인도 메시지 표현("invalid literal")과 거의 같게 추측

### 3일차 (2026-10-07) — [[input]]
#### 복습 (안 보고) — 모두 정답
- `"4" * 2` → `44` / `4 * 2` → `8` / `int("4") + 4` → `8` ✅
- `print(item+"상품 "+str(stock)+"개")` → `A상품 140개` (출력 형식 정확) ✅
- `"Week " + 3` → `TypeError`, `int("1,000")` → `ValueError` ✅

#### 개념
- `input("안내문")` = 안내문을 보여주고 입력을 기다림. 비유: 웹사이트 입력 폼 (숫자를 써도 글자로 전달됨)
- **입력은 숫자를 쳐도 항상 문자열** → 계산하려면 `int()`
- 변환 시점 두 가지:
  - 쓸 때 변환: `price = input(...)` → `int(price)*2` (쓸 때마다 `int()` 필요)
  - 받자마자 변환: `price = int(input(...))` → 이후엔 그냥 숫자 (여러 번 쓸 때 편함)
- 코랩: 입력 칸에 입력 후 Enter를 눌러야 다음 줄로 진행

| 문제 | 내 답 | 결과 | 확인하려는 개념 |
|---|---|---|---|
| 타이핑 1 | `print(name +"님 안녕하세요")` | ✅ | 입력값(문자열) 이어 붙이기 |
| 타이핑 2 | `print(int(price)*2)` | ✅ | 입력값 → `int()` → 계산 (쓸 때 변환) |
| 1. `7` 입력, `x + x` / `int(x) + int(x)` 예측 | `77` / `14` | ✅ | 입력은 문자열 |
| 2. 분·초 입력 → `총 135초` | `print("총",str(int(minutes)*60+int(seconds))+"초")` | ✅ | 1주차부터 이어진 문제의 최종 버전 |
| 3. 기호·횟수 입력 → `---` | `print(symbol*int(times))` | ✅ | 반복 횟수만 `int()`, 기호는 문자열 그대로 |
| 4. `quantity + 10` 에러 추측 | `TypeError`, 고치려면 `int(quantity) + 10` | ✅ | 에러 예측 + 수정 |

- 문제 2: 쉼표(공백 자동)와 `+`(공백 없음)를 **섞어서** 형식을 정확히 맞춤
  - `총` 뒤엔 공백 필요 → 쉼표 / `135`와 `초`는 붙여야 함 → `+` (그래서 `str()` 필요)
  - 쉼표만 쓰면 `총 135 초`가 되어 형식이 틀림
