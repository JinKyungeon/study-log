## 오늘 배운 것 / 헷갈린 것
### 1일차 (2026-10-07) — [[자료형]]: 숫자 vs 문자열
- `type(값)` = 값의 종류를 **알아내기만** 함 → 보려면 `print(type(3.5))` (괄호 두 겹 `))`)
  - **헷갈렸다가 이해함:** `type(3.5)`만 쓰면 아무것도 안 나옴
  - 계산하기 / 저장하기(`=`) / 보여주기(`print`)는 각각 따로 시켜야 하는 일
    - `print(bpm+20)` = 보여주기만, 저장 X (1주차 3일차)
    - `type(3.5)` = 알아내기만, 보여주기 X
  - 코랩은 셀 **마지막 줄**의 값을 자동으로 보여주지만 원래 파이썬에선 안 됨 → 항상 `print`
- 문자열 `+` = 이어 붙이기: `"Do" + "Re"` → `DoRe`, `"10" + "20"` → `1020`
- 문자열 `*` = 반복: `"Am " * 4` → `Am Am Am Am ` (따옴표 안 공백도 반복됨)
- `*`가 `+`보다 먼저: `"C" * 2 + "G"` → `CC` + `G` → `CCG`
- 문자열 + 숫자 → `TypeError: can only concatenate str (not "int") to str`
  - 에러 메시지를 읽고 원인을 **스스로 추측해서 맞힘** ("타입이 매칭이 안 돼서")

| 문제 | 내 답 | 결과 | 확인하려는 개념 |
|---|---|---|---|
| 1-1 `type(3.5)` | `print` 없이 실행 → 아무것도 안 나옴 → `print(type(3.5))` | ⚠️→✅ | `type()` 사용법, 보여주기는 `print` |
| 1-2 `"Do" + "Re"` | `print("Do" + "Re")` | ✅ | 문자열 `+` |
| 1-3 `"Am " * 4` | `print("Am " *4)` | ✅ | 문자열 `*` |
| 2-1 `10 + 20` / `"10" + "20"` 예측 | `30` / `1020` | ✅ | 숫자 `+` vs 문자열 `+` |
| 2-2 `type("3.5")` 예측 | `float` | ❌ 정답 `<class 'str'>` | **따옴표가 있으면 숫자처럼 보여도 문자열** |
| 2-3 `"C" * 2 + "G"` 예측 | `CCG` | ✅ | 문자열 연산 + 계산 순서 |
| 4 `"BPM " + 120` 에러 추측 | "타입이 매칭이 안 돼서" | ✅ | `TypeError` 읽기 |

- **틀린 점:** `"3.5"`를 겉모양만 보고 실수라고 판단 → 종류는 **따옴표**가 결정한다
  - 2-1에서 `"10" + "20"` → `1020`은 맞혔으니 원리는 앎. 하지만 `type()` 문제에선 놓침 → 다음 세션 재확인

#### 보너스: `"BPM " + 120` 에러 고치기 → `BPM 120`
| 방법 | 내 답 | 결과 |
|---|---|---|
| 1. 쉼표 | `print("BPM", "120")` | ✅ (`120` 그대로 둬도 됨: 쉼표는 종류가 달라도 OK) |
| 2. `+` | `print("BPM " +"120")` | ✅ |

- **스스로 정리한 규칙:** 쉼표는 공백 한 칸을 **자동으로** 넣고, `+`는 넣지 않는다 → `+`를 쓸 땐 문자열 안에 공백을 직접 넣어야 한다
- 쉼표 = 종류가 달라도 나란히 출력 / `+` = 종류가 같아야 하고 빈틈없이 이어 붙임
