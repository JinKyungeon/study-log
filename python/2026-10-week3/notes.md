## 오늘 배운 것 / 헷갈린 것
### 1일차 (2026-10-11) — [[조건문]] `if`
#### 개념
- 지금까진 `True`/`False`를 **보여주기만** 했다면, `if`는 그 결과로 **할 일을 정함**
- 문법: 조건 끝에 `:`, 속한 줄은 **들여쓰기**(표준 스페이스 4칸)
- 들여 쓴 줄 = `if`에 속함 (조건 `True`일 때만) / 안 들여 쓴 줄 = 항상 실행

| 문제 | 내 답 | 결과 | 확인하려는 개념 |
|---|---|---|---|
| 타이핑: 재고 0이면 `품절`, 항상 `확인 끝` | `if` 줄까지 들여 씀 → `IndentationError` → 에러 읽고 수정 | ⚠️→✅ | 들여쓰기는 "위의 `if`에 속한다"는 표시 |
| 타이핑: `stock = 5`이면? | `확인 끝`만 | ✅ | 조건 `False`면 건너뜀 |
| 1. `score = 55`, 두 줄 다 들여 씀 | `채점 완료`만 | ✅ | `False`면 블록 전체 건너뜀 |
| 2. `print("축하합니다")`만 밖으로 | `축하합니다` / `채점 완료` | ✅ | **들여쓰기 한 칸이 의미를 바꿈** |
| 3. 주문 금액 50000원 이상 `무료 배송`, 항상 `주문 접수` | 로직 정답, 안내문 `"주문 금액:"` 공백 누락 → 힌트 후 수정 | ⚠️→✅ | `input` + `if` 종합 |

- `IndentationError: unexpected indent` = 예상 못 한 들여쓰기. `if` 줄 위에는 속할 `if`가 없으니 맨 앞에 써야 함
- 들여쓰기 2칸도 동작하지만 표준은 4칸, 한 블록 안에서는 칸 수를 통일 (섞이면 `IndentationError`)
- 예측 답에 `채점완료`(띄어쓰기 빠짐) → 내용은 정답, 형식은 계속 체크
