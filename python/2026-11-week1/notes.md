# 11월 1주차 — 리스트 `[ ]`

## 개념 요약
- [[리스트]] `[값, 값, 값]` — 번호는 **0부터**, 마지막 번호 = `len - 1`, 없는 번호는 `IndexError`
- `len(리스트)` = 개수 → 평균은 `합계 / len(리스트)`
- `for x in 리스트:` — `range` 대신 리스트를 바로 넣으면 값이 하나씩
- 최댓값 패턴: `max_x = 리스트[0]`으로 시작 → 더 크면 바꾸기 (최솟값은 부등호만 반대)
- `빈 리스트 = []` → `리스트.append(값)`으로 맨 뒤에 추가. `for` + `input` + `append` = 입력값을 모두 남기기
- 순서: **모으기(반복 ①) → 분석(반복 ②)**. 다 모은 뒤라야 `리스트[0]`으로 시작할 수 있다

### 문제 1 — 무엇이 왜 틀렸나 (자세히)

**① `append` 없음 → `[]`**
`daily_sale`은 상자 하나라 바퀴마다 **덮어써지고**, `daily_sales`는 아무도 넣어 주지 않아 `[]` 그대로. 이름이 비슷해도 파이썬이 알아서 모아 주지 않는다 → 덮어써지기 전에 `daily_sales.append(daily_sale)`로 옮겨 담기.

| 바퀴 | `daily_sale` | `append` 없음 | `append` 있음 |
|---|---|---|---|
| 1 | 12000 | `[]` | `[12000]` |
| 2 | 8500 (12000 사라짐) | `[]` | `[12000, 8500]` |
| 3 | 15000 | `[]` | `[12000, 8500, 15000]` |

**② 반복 하나 + `max_sales = 0`**
- `0` 시작은 매출이 양수라 **운 좋게** 맞음. 손익 `[-3000, -500, -1200]`이면 답이 리스트에 없는 `0` (11-09 기온 함정과 같음)
- 반복 하나 구조에선 `daily_sales[0]`도 못 씀 — 반복 전엔 리스트가 `[]`라 `IndexError: list index out of range`
- 그래서 **① 모으기(`append`만) → ② 분석(`max_sales = daily_sales[0]` 후 `for daily_sale in daily_sales:`)**. 12월 CSV도 "읽어서 담기 → 계산" 순서. 나눠 두면 분석만 바꿔 다시 쓸 수 있다

| 바퀴 (반복 ②) | `daily_sale` | `max_sales` | `>= 10000` 개수 |
|---|---|---|---|
| 시작 | | 12000 | 0 |
| 1 | 12000 | 12000 (같으면 안 바뀜) | 1 |
| 2 | 8500 | 12000 | 1 |
| 3 | 15000 | **15000** | 2 |
| 4 | 7000 | 15000 | 2 |
| 5 | 11000 | 15000 | **3** |

**③ `> 100000`**
- 0 개수: `10000` = 1만, `100000` = **10만** → 아무 날도 안 셈. 긴 숫자는 0 세기 (`10_000`처럼 밑줄도 가능)
- "이상/이하" = 경계 포함 `>=`/`<=`, "초과/미만" = 미포함 `>`/`<`. `> 10000`이면 딱 10000원인 날이 빠짐

| 실수 | 원인 | 기억할 것 |
|---|---|---|
| `[]`만 출력 | `append` 없음 → 변수만 덮어써짐 | 리스트에 넣는 건 내가 직접 `.append()` |
| 반복 하나 + `0` 시작 | 빈 리스트에선 `[0]` 못 꺼냄 | 모으기 → 분석, 시작값은 리스트 안의 값 |
| `> 100000` | 0 개수, "이상"의 뜻 | 0 세기, 이상 = `>=` |

- 생각 질문 "왜 `if`/`else`?" → "합격 아니면 나머지는 재시험" (핵심 정답). 이유는 점수 범위가 아니라 조건 답이 **True/False 둘 중 하나**라서
  - 한 값이 **둘 중 하나에만** → `if`/`else`, **여러 곳에 동시에** → `if` 여러 개
- `max < x`와 `x > max`는 같은 뜻 (좌우 바꾸면 부등호도 뒤집기)
- 마지막 줄 오답 원인: 괄호 안 리스트 이름을 안 보고 위의 `reorder_items`나 `[0]`으로 계산 → **괄호 안 이름부터**
