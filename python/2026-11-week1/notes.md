# 11월 1주차 — 리스트 `[ ]`

## 이번 주 목표
- [x] 값 여러 개를 리스트 하나에 담고, 번호(인덱스)로 꺼낸다
- [x] `for`로 리스트를 돌며 합계·개수·조건 세기를 한다
- [ ] 리스트에 값을 추가한다

## 개념 요약
- [[리스트]] `[값, 값, 값]` — 번호는 **0부터**, 마지막 번호 = `len - 1`, 없는 번호는 `IndexError`
- `len(리스트)` = 개수 → 평균은 `합계 / len(리스트)`
- `for x in 리스트:` — `range` 대신 리스트를 바로 넣으면 값이 하나씩
- 최댓값 패턴: `max_x = 리스트[0]`으로 시작 → 더 크면 바꾸기

| 2. 미세먼지 7일 — 나쁨(80 이상)만 출력·개수, 평균 | 출력 **한 번에 정답**. 합계 변수 이름을 `average_pm10`, 일수를 반복으로 또 셈 → 질문 후 `total_pm10`, `day_count = len(...)` | ⚠️→✅ | `if` 안/밖 들여쓰기 구분, 반복 안 합계 + 반복 뒤 평균, 역할에 맞는 이름 |
| 3. 최고 점수 (`max()` 없이) | 최댓값 패턴 **한 번에**. 함정 질문(기온 `[-5, -3, -9]`)에 "0 나옴" 바로 답 → `max_score = scores[0]`으로 수정 | ✅ | 최댓값 패턴, 시작값은 리스트 **안의** 값 |
