## 1. 구글 코랩 세팅
1. https://colab.research.google.com 접속 → 구글 계정 로그인
2. `파일 → 새 노트` → 제목을 `2026-10-week1.ipynb`로 변경
3. 회색 칸(= **셀**)에 코드 입력 → `Shift + Enter`로 실행
4. 노트북은 구글 드라이브의 `Colab Notebooks` 폴더에 자동 저장됨
5. 다 푼 코드는 이 폴더의 `practice.py`에도 옮겨 적어 기록한다
