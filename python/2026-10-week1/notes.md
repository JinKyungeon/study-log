## 오늘 배운 것 / 헷갈린 것
### 1일차 (2026-09-29) — 코랩, [[print]]
- 코랩: 셀 실행은 `Shift + Enter`, 결과는 셀 바로 아래에 나온다
- 따옴표가 있으면 글자, 없으면 숫자·계산 → `print(12*5)`는 `60`
- **헷갈렸다가 이해함:** 쉼표의 두 역할
  - 따옴표 **안** 쉼표 → 글자: `print("F,C,G")` → `F,C,G`
  - 따옴표 **밖** 쉼표 → 구분 기호(출력 안 됨, 공백으로): `print("Am", "F", "C", "G")` → `Am F C G`
  - 비유: 가사 속 쉼표 vs 악보의 마디선
- 글자와 계산을 섞을 수 있다: `print("3분 30초=", 3*60+30)` → `3분 30초= 210`
- `#` 뒤는 **주석** — 파이썬이 무시하는 메모
- 곱셈이 덧셈보다 먼저 계산된다: `3*60+30` = `180+30`

### 문제 의도 — 무슨 개념을 확인하려고 낸 문제인가
| 문제 | 코드 | 확인하려는 개념 |
|---|---|---|
| 타이핑 ① | `print("Kyungeon")` | 따옴표 = 글자, 그대로 출력 |
| 타이핑 ② | `print(12*5)` | 따옴표 없음 = 값·계산 → `60` (①과 대비) |
| 타이핑 ③ | `print("Am", "F", "C", "G")` | 따옴표 밖 쉼표 = 구분 기호 → 공백으로 출력 |
| 문제 1 | `print("안녕하세요")` + `print("저는 경언입니다.")` | `print` 한 번 = 한 줄 (끝나면 자동 줄바꿈) |
| 문제 2 | `print("3분 30초=", 3*60+30)` | ①②③ 조합: 글자+계산 섞기 / 따옴표 안 `=`는 그냥 글자 / 곱셈 먼저 / 실생활 문제를 식으로 옮기기 |
| 문제 3 | `print("BPM 120의 두배는", 120*2)` | 문제 2와 **같은 구조**, 소재만 바꿈 → 외운 게 아니라 패턴을 이해했는지 확인 |
| 틀린 문제 | `Am F C G` 출력 | 쉼표 따옴표 안(글자) vs 밖(구분 기호) — 헷갈리는 지점을 일부러 드러내는 문제 |
| 내일 체크 | 1분 45초 → 초 | 문제 2를 하루 뒤 안 보고 다시 풀기 (인출 연습) |

> 핵심: 타이핑 3줄이 `print`의 뼈대(글자 / 계산 / 쉼표)이고, 문제 1~3은 그 조합이다.
> 풀 때 요령: 실행하기 **전에** 출력을 먼저 예측해 보기. 틀리면 그게 약한 개념.
