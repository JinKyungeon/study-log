## 오늘 배운 것 / 헷갈린 것
### 1일차 (2026-09-29) — 코랩, [[print]]
- 코랩: 셀 실행은 `Shift + Enter`, 결과는 셀 바로 아래에 나온다
- 따옴표가 있으면 글자, 없으면 숫자·계산 → `print(12*5)`는 `60`
- **헷갈렸다가 이해함:** 쉼표의 두 역할
  - 따옴표 **안** 쉼표 → 글자: `print("F,C,G")` → `F,C,G`
  - 따옴표 **밖** 쉼표 → 구분 기호(출력 안 됨, 공백으로): `print("Am", "F", "C", "G")` → `Am F C G`
  - 비유: 가사 속 쉼표 vs 악보의 마디선
- 글자와 계산을 섞을 수 있다: `print("3분 30초=", 3*60+30)` → `3분 30초= 210`
- `#` 뒤는 **주석** — 파이썬이 무시하는 메모
- 곱셈이 덧셈보다 먼저 계산된다: `3*60+30` = `180+30`

### 2일차 (2026-10-07) — 1일차 인출 연습 결과
| 문제 | 내 답 | 결과 |
|---|---|---|
| A. `Am F C G` 출력 | `print("Am", "F", "C", "G")` | ✅ |
| B. 1분 45초 → 초 | `print("1분 45초=", 60*1+45)` | ✅ |

- **틀린 점:** 따옴표 **밖** 쉼표도 화면에 찍힌다고 예측함

- 요령: 출력 예측할 때 따옴표 밖 쉼표를 손가락으로 가리고 그 자리에 공백 한 칸을 넣어 보기

### 2일차 (2026-10-07) — [[변수]]
- `=`는 "같다"가 아니라 **"오른쪽 값을 왼쪽 이름에 넣어라"** → 항상 오른쪽부터 읽는다
  - 그래서 `bpm = bpm + 20`이 말이 된다: 지금 bpm(100) + 20 → 다시 bpm에 → `120`
- 다시 넣으면 값이 바뀐다: `bpm = 120` 후 `bpm = 90` → `90`
- 따옴표 규칙이 변수에도 그대로: `print(chord)` → `Am` (값) / `print("chord")` → `chord` (글자)
- 변수 이름도 대소문자 구분: `song`과 `Song`은 다른 변수 → `NameError`
- 따옴표 **안** 글자는 대소문자까지 그대로 출력: `"yesterday"` → `yesterday`

| 문제 | 내 답 | 결과 | 확인하려는 개념 |
|---|---|---|---|
| 타이핑 | `song`, `bpm*2`, `bpm = 90` | ✅ | 변수에 넣기 / 계산에 쓰기 / 다시 넣으면 바뀜 |
| 1. 총 초 | `print("총 초=" minutes*60+seconds)` → 고침 | ⚠️→✅ | 숫자 대신 변수 이름으로 계산 (1일차 문제 2의 변수 버전) |
| 2. 예측 | `chord Am` / `Am F C` | ✅ | 밖 쉼표 = 공백 (오전에 틀린 것 재도전) + 따옴표 있는 이름 vs 없는 이름 |
| 3. 예측 | `120` | ✅ | `=`는 오른쪽부터 → `bpm = bpm + 20` |

- **헷갈렸다가 해결:** 문제 1에서 글자와 계산 사이 쉼표를 빠뜨림 → `SyntaxError`
  - 오전에는 밖 쉼표가 "찍힌다"고 착각, 오후에는 쉼표를 "빠뜨림" → 쉼표는 **글자와 값 사이를 구분하는 필수 신호**
  - 에러 메시지 마지막 줄 `Perhaps you forgot a comma?`가 답을 알려 준다

### 3일차 (2026-10-07) — [[변수]] 인출 연습 결과
| 문제 | 내 답 | 결과 |
|---|---|---|
| A. 4분 15초 → 초 | `print("총 초", minutes*60 + seconds)` | ⚠️ 계산은 맞음, 출력 `총 초 255`로 `=` 누락 |
| B. bpm 20 올리기 | `print(bpm+20)` | ⚠️ 화면엔 `120`, 하지만 `bpm`은 여전히 `100` |
| C. `print("name", name)` 예측 | `name Kyungeon` | ✅ |
| D. `print("Key,", key, "major")` 예측 | `Key, G major` | ✅ |
| D. `print(key, "=", 7)` 예측 | `G = 7` | ✅ |

- **쉼표 해결:** 따옴표 안 쉼표(`"Key,"`)는 글자, 밖 쉼표는 공백 → 예측 3개 모두 정답
- **새로 알게 된 것:** "계산해서 보여주기"와 "변수 값 바꾸기"는 다르다
  ```python
  bpm = 100
  print(bpm+20)    # 120  ← 계산 결과를 보여주기만 함
  print(bpm)       # 100  ← bpm은 그대로!
  bpm = bpm + 20   # 이렇게 다시 넣어야 바뀐다
  print(bpm)       # 120
  ```
  - 비유: 트랙 볼륨을 머릿속으로 +20 해 보는 것 vs 실제로 페이더를 올려 저장하는 것
- 예측 답을 `#` 주석으로 코드 옆에 적는 습관 → 좋은 방법. 실행 후 바로 비교 가능
