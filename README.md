# 전과 대비 프로그래밍 스터디 (2026.10 ~ 2027.03)

철학과 → 융합소프트웨어학부 데이터사이언스 전공 전과를 위한 6개월 파이썬·자바 기초 학습 기록.
진행 상황은 [[progress]]에서 관리한다.

## 공부 방식
- 하루 1~2시간, 주 5일
- 흐름: 개념 설명 → 예제 안 보고 직접 타이핑 → 작은 문제 3~5개 → 다음 날 안 보고 다시 짜기
- 막히면 힌트부터, 에러 메시지는 먼저 직접 읽어보기
- 매월 4주차는 새 개념 없이 점검·복습

## 6개월 계획

| 월 | 주제 | 상태 |
|---|---|---|
| 2026-10 | 파이썬 기초: 변수, 자료형, 조건문, 반복문 | 🟡 진행 중 |
| 2026-11 | 리스트/딕셔너리, 함수, 파일 입출력, 예외 처리 | ⬜ |
| 2026-12 | 클래스, 넘파이/판다스, **미니 프로젝트 1** (공공데이터 CSV 분석) | ⬜ |
| 2027-01 | 자바 문법 (파이썬과 비교), IDE 세팅 | ⬜ |
| 2027-02 | 자바 객체지향, 컬렉션 | ⬜ |
| 2027-03 | 복습, 문제 풀이, **미니 프로젝트 2** (자바 콘솔 프로그램) | ⬜ |

### 10월 세부 계획
| 주차 | 주제 |
|---|---|
| 1주차 | 구글 코랩 세팅, `print`, 변수 |
